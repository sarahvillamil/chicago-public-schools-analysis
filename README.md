# Chicago Public Schools College Enrollment Analysis
### chicago-public-schools-analysis
Data cleaning, integration, and statistical analysis of CPS and Chicago demographic datasets using R.
 
## Overview
This project explores factors associated with college enrollment outcomes across Chicago Public Schools.
 
Using Chicago Public Schools performance data and Chicago demographic data, I analyzed how school type, attendance, graduation outcomes, and community characteristics relate to college enrollment rates.
 
## Tools
- R
- dplyr
- ggplot2
- Statistical Analysis
- Data Visualization
 
## Dataset
- Chicago Public Schools School Progress Report Data
- Chicago Community Demographic Data
- 1,298 observations
- 39 variables
 
## Key Findings
- Higher attendance rates were positively associated with college enrollment.
- Graduation and persistence rates showed strong positive relationships with enrollment outcomes.
- Chronic truancy, mobility, and dropout rates were negatively associated with college enrollment.
