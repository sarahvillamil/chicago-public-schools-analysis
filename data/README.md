## Chicago Public Schools Final Project EDA - Data Folder
This repository contains the process of EDA completed on Chicago Public Schools and Chicago Demographic Data.

## Elements of Data Folder

-['raw/'](raw): contains raw data from source
-['neighborhoods_chi/'](neighborhoods_chi): contains neighborhood data of Chicago from Professor Sass
-['zipcode_chi/'](zipcode_chi): contains zipcode data of Chicago from Professor Sass

### CSVs
-   'cps_and_demographic_codebook.csv': file with codebook of cleaned dataset of Chicago Public Schools and Demographic Data

### RDSs
-   'cps_and_demographic_cleaned.rds': cleaned and joined file for Chicago Public Schools and Demographic Data
