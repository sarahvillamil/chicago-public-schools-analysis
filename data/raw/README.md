## Chicago Public Schools Final Project EDA - Raw Folder
This repository contains the process of EDA completed on Chicago Public Schools Data and Chicago Demographic Data.

## Elements of Raw Folder

### CSVs

-   'Chicago_Demographic_data.csv': file for imported Chicago Demographic Data.
  [Chicago Demographic Data](https://data.cityofchicago.org/Community-Economic-Development/ACS-5-Year-Data-by-Community-Area/t68z-cikk/data_preview) 
  sourced from the [City of Chicago Data Portal](https://data.cityofchicago.org/).
-   'Chicago_public_schools.csv': file for imported Chicago Public Schools Data.
  [Chicago Public Schools Data](https://data.cityofchicago.org/Education/Chicago-Public-Schools-School-Progress-Reports-SY2/twrw-chuq/about_data)
  sourced from [City of Chicago Website](https://www.cps.edu/).
